英語名一覧ダジャレ怖い図鑑クイズ

英語名がダジャレなポケモンまとめ

英語名の由来を知るともっと面白い

ポケモンの英語名は、英単語を組み合わせたダジャレになっているものがたくさんあります。由来を知るとつい誰かに話したくなるものを集めました。

ウソッキー → Sudowoodo

英語名「Sudowoodo」は、pseudo（にせの）とwood（木）を組み合わせた名前と考えられている。フランス語の名前は「Simularbre」で、simulacre（にせもの）、arbre（木）から作られている。

ヤドン → Slowpoke

ドイツ語の名前は「Flegmon」で、怪物から作られている。

ソーナンス → Wobbuffet

英語名「Wobbuffet」は、wobble（ぐらぐら揺れる）とbuffet（打ちのめす）を組み合わせた名前と考えられている。フランス語の名前は「Qulbutoké」で、culbuto（起き上がりこぼし）、okay（オーケー）から作られている。

カモネギ → Farfetch'd

英語名「Farfetch'd」は、far-fetched（こじつけの）とunbelievable（信じられない）を組み合わせた名前と考えられている。フランス語の名前は「Canarticho」で、canard（カモ、またはデマ）、artichaut（アーティチョーク）から作られている。

スリーパー → Hypno

英語名「Hypno」は、hypnosis（催眠）がもとになっていると考えられている。フランス語の名前は「Hypnomade」で、hypnose（催眠）、nomade（遊牧民）から作られている。

ベロリンガ → Lickitung

英語名「Lickitung」は、lick（なめる）とtongue（舌）を組み合わせた名前と考えられている。フランス語の名前は「Excelangue」で、excellent（すばらしい）、langue（舌）から作られている。

ツボツボ → Shuckle

英語名「Shuckle」は、shuck（殻）、barnacle（フジツボ）とturtle（カメ）を組み合わせた名前と考えられている。ドイツ語の名前は「Pottrott」で、Pott（「つぼ」のくだけた言い方）、verrotten（腐る）から作られている。

ヤミラミ → Sableye

英語名「Sableye」は、sable（クロテン）とeye（目）を組み合わせた名前と考えられている。フランス語の名前は「Ténéfix」で、ténèbre（闇）、fixer（じっと見る）から作られている。

ビッパ → Bidoof

英語名「Bidoof」は、beaver（ビーバー）とdoofus（まぬけ）を組み合わせた名前と考えられている。フランス語の名前は「Keunotor」で、quenotte（乳歯）、castor（ビーバー）から作られている。

ウッウ → Cramorant

英語名「Cramorant」は、cram（詰めこむ）とcormorant（ウ（鳥））を組み合わせた名前と考えられている。フランス語の名前は「Nigosier」で、nigaud（まぬけ、または小さなウ）、gosier（のど）から作られている。

ドヒドイデ → Toxapex

英語名「Toxapex」は、toxic（有毒な）とapex（頂点）を組み合わせた名前と考えられている。フランス語の名前は「Prédastérie」で、prédateur（捕食者）、astérie（ヒトデ）から作られている。

クレッフィ → Klefki

英語名「Klefki」は、clef（音部記号）、key（鍵）とkleftis（ギリシャ語で「泥棒」）を組み合わせた名前と考えられている。ドイツ語の名前は「Clavion」で、clāvis（ラテン語で「鍵」）、イオンから作られている。

ナッシー → Exeggutor

英語名「Exeggutor」は、egg（卵）とexecutor（執行者）を組み合わせた名前と考えられている。ドイツ語の名前は「Kokowei」で、Kokosnuss（ココナッツ）、Owei（タマタマ）から作られている。

プリン → Jigglypuff

英語名「Jigglypuff」は、jiggly（ぷるぷるした）とpuff（ふくらむ）を組み合わせた名前と考えられている。ドイツ語の名前は「Pummeluff」で、pummelig（ぽっちゃりした）、fluff（綿毛）から作られている。

カビゴン → Snorlax

英語名「Snorlax」は、snore（いびき）、lax（ゆるい）とlackadaisical（ものぐさな）を組み合わせた名前と考えられている。ドイツ語の名前は「Relaxo」で、relax（くつろぐ）から作られている。

ミミッキュ → Mimikyu

英語名「Mimikyu」は、mimic（まねる）がもとになっていると考えられている。フランス語の名前は「Mimiqui」で、mimique（まねる）、qui（だれ）から作られている。

モンジャラ → Tangela

英語名「Tangela」は、tangle（からまる）と-ella（小さいものを表す語尾）を組み合わせた名前と考えられている。

コダック → Psyduck

英語名「Psyduck」は、psy-（「心の」を表す接頭語）、psychic（超能力）とduck（カモ）を組み合わせた名前と考えられている。フランス語の名前は「Psykokwak」で、psychique（超能力）、couac（ガーガー）から作られている。

コイキング → Magikarp

英語名「Magikarp」は、magic（魔法）とcarp（コイ）を組み合わせた名前と考えられている。フランス語の名前は「Magicarpe」で、magique（魔法）、carpe（コイ）から作られている。

ラッキー → Chansey

英語名「Chansey」は、chance（偶然）とchancy（運まかせの）を組み合わせた名前と考えられている。フランス語の名前は「Leveinard」で、le veinard（幸運な者）から作られている。

ジュゴン → Dewgong

英語名「Dewgong」は、dew（露）とdugong（ジュゴン）を組み合わせた名前と考えられている。フランス語の名前は「Lamantine」で、lamantin（マナティー）、comptine（童謡）から作られている。

アズマオウ → Seaking

英語名「Seaking」は、sea（海）、king（王）とseeking（「探す」のもじり）を組み合わせた名前と考えられている。ドイツ語の名前は「Golking」で、Goldfisch（金魚）、king（王）から作られている。

サワムラー → Hitmonlee

英語名「Hitmonlee」は、hit（打つ）とmonster（怪物）を組み合わせた名前と考えられている。フランス語の名前は「Kicklee」で、kick（キック）、ブルース・リーから作られている。

エビワラー → Hitmonchan

英語名「Hitmonchan」は、hit（打つ）とmonster（怪物）を組み合わせた名前と考えられている。フランス語の名前は「Tygnon」で、マイク・タイソン、gnon（ドスン）から作られている。

マタドガス → Weezing

英語名「Weezing」は、wheezing（ゼーゼー息をする）がもとになっていると考えられている。ドイツ語の名前は「Smogmog」で、Smog（スモッグ）から作られている。

キングラー → Kingler

英語名「Kingler」は、king crab（タラバガニ）とangler（釣り人）を組み合わせた名前と考えられている。フランス語の名前は「Krabboss」で、crabe（カニ）、boss（ボス）から作られている。

サンド → Sandshrew

英語名「Sandshrew」は、sand（砂）とshrew（トガリネズミ）を組み合わせた名前と考えられている。フランス語の名前は「Sabelette」で、sable（砂）、belette（イタチ）から作られている。

キュウコン → Ninetales

英語名「Ninetales」は、nine（9）とtales（物語）を組み合わせた名前と考えられている。フランス語の名前は「Feunard」で、feu（火）、renard（キツネ）、neuf（9）から作られている。

ラフレシア → Vileplume

英語名「Vileplume」は、vile（卑劣な）がもとになっていると考えられている。フランス語の名前は「Rafflesia」で、Rafflesia（ラフレシア）から作られている。

ドククラゲ → Tentacruel

英語名「Tentacruel」は、tentacle（触手）とcruel（残酷な）を組み合わせた名前と考えられている。ドイツ語の名前は「Tentoxa」で、Tentakel（触手）、toxisch（有毒な）から作られている。
